# BIEXCE Plan/Build Rules

- The user is the highest authority for scope and product decisions.
- Preserve the existing project structure unless a change is necessary.
- Prefer small, maintainable changes over speculative architecture.
- Load only the BIEXCE skills relevant to the current task.
- Never expose secrets or modify files outside the active project without approval.
- Do not claim completion until the relevant checks have actually passed.
- Do not disable or weaken tests merely to obtain a passing result.
- Ask the user only when a missing decision materially changes the product or risk.
