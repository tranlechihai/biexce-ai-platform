# Organization conventions

This skill is intentionally unavailable. It prevents agents from inventing
company naming, repository layout, language, formatting or ownership rules.

To activate it, the organization must supply an approved engineering handbook
or equivalent source covering naming, directory layout, supported languages,
formatters, generated files and exception ownership. Replace this file with a
reviewed `ready` skill and regenerate the manifest.
